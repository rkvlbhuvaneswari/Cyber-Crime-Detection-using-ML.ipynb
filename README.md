# Cyber Crime Detection using Machine Learning

## Project Overview

This project uses Machine Learning techniques to detect
and classify cyber crime-related data.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Data Analysis
4. Feature Selection
5. Model Training
6. Model Prediction
7. Model Evaluation

## Project File

The complete implementation is available in the Jupyter Notebook.

## Conclusion

This project demonstrates how Machine Learning can be
used for cyber crime detection and classification.
